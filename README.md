## 2. Project Title

Time and Duration Calculator

---

## 3. Project Description

This program is a simple calculator designed to calculate the duration between two given times. Users can input a starting time and an ending time, and the program will determine the time difference between them. This project helps users calculate time intervals accurately and efficiently, making it useful for scheduling activities, tracking working hours, and managing daily tasks.

---

## 4. Objectives

This project is designed to apply the following programming concepts:

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript

---

## 5. Input

The program receives:

- Start hour
- Start minute
- End hour
- End minute

---

## 6. Process

The program compares the player's guess with the target number.

If the guess is:

- Too high → the program provides a "too high" message
- Too low → the program provides a "too low" message
- Correct → the player wins
